## 0. 프로젝트 개요

- 광운대학교 전자공학 동아리 KITEL의 홈페이지를 **기존 XpressEngine(XE) 기반 → Rhymix 기반**으로 마이그레이션.
- 단순 엔진 교체가 아니라 **디자인 전면 개편 + 메뉴/기능 재설계**를 함께 진행 중.
- 아래 내용은 팀 내부 논의로 이미 확정된 사이트 구조이며, 이 문서를 기준으로 Figma 디자인을 시작할 수 있는 상태.

## 1. 전체 메뉴 구조

```
About (전체공개, 관리자만 작성)
├── 키텔 소개 (연혁 / 활동 / 연구분야)
├── 임원진 소개 및 인사말
├── 일정 (캘린더)
└── 회칙

Kitel News (공지사항)
├── 동아리 내 경사
├── 최근 진행 행사 보고
└── 기업방문·세미나 등 일정 공고

Study
├── 자료실           — 정회원 전용, 기존 NAS Drive 이관
├── 과제게시판        — 준회원 제출 + 기술부 관리
├── 작품전시회 게시판  — 구 축제게시판, 전체공개 갤러리
├── 세미나 게시판      — 정회원 발표자료 아카이브
└── 공유 게시판       — 정회원 전용, 우선 빈 게시판으로 오픈

기타 (메뉴명 미정)
├── 건의사항
├── Contact Us
└── 기자재 대여 시스템 (기존 구현 유지, 진입점만 배치)
```

## 2. 회원 등급 & 화면에 영향을 주는 권한

방문자 유형은 크게 5단계: **비로그인 → 준회원 → 정회원(=졸업생 특별회원 동일 취급) → 임원진 → admin**. 이 중 화면 디자인에 실제로 영향을 주는 부분만 정리하면:

| 화면 | 등급별로 달라지는 부분 |
|---|---|
| Kitel News | 비로그인/미가입 상태에서 글 목록의 **제목은 보이지만 본문은 잠금**(다음/네이버 카페 스타일 "로그인 후 확인 가능" UI 필요) |
| 과제게시판 | 준회원은 **본인 제출물만**, 정회원 이상은 **전체 열람** — 같은 목록이라도 보이는 범위가 사용자마다 다름 |
| 작품전시회 게시판 | 작성 후 **검토중 → 승인 → 공개** 상태가 있어, 공개 갤러리에는 승인된 작품만 노출 (관리자용 검토 화면 별도 필요) |
| 건의사항 | 작성자가 익명 체크 시 **모두에게(운영진 포함) "익명"으로 표시** |
| 캘린더 | 등록/수정 버튼은 admin에게만 보이고, 나머지는 조회 전용 |
| 자료실 | 정회원 전용이라 비회원/준회원에게는 이 메뉴 자체가 잠겨 있음 |

## 3. Figma에서 만들어야 할 화면 — 3가지 유형

Rhymix는 "공통 레이아웃(헤더/푸터/GNB)"과 "게시판별 화면(스킨)"이 분리된 구조입니다. 이 프로젝트의 화면들은 작업 방식이 서로 다른 3가지 유형으로 나뉩니다.

### (A) 공통 레이아웃 — 전 페이지 공통
헤더 / 푸터 / GNB(위 1번 메뉴 구조 전체) / 로그인 상태별 GNB 노출 차이.

### (B) 표준 게시판형 화면 — "목록 / 상세 / 글쓰기" 3종 세트로 반복되는 패턴
아래 게시판들은 전부 이 3종 화면(+ 상태 변형)으로 커버됩니다.

| 게시판 | 목록 | 상세 | 글쓰기 | 추가로 필요한 상태 |
|---|---|---|---|---|
| Kitel News | ✅ | ✅ | ✅(admin만) | 비회원/미가입 잠금 상태 |
| 세미나 게시판 | ✅ | ✅ | ✅(정회원) | — |
| 공유 게시판 | ✅ | ✅ | ✅(정회원) | 빈 게시판 상태(초기 오픈 시) |
| 건의사항 | ✅(작성자·임원진만) | ✅ | ✅(정회원) | 익명 표시 상태 |
| 자료실 | 폴더/파일 목록 | 파일 상세(다운로드) | 업로드/폴더생성 | 빈 폴더 상태 |
| 과제게시판 | 과제 목록 + 제출 목록 | 과제 상세, 제출 상세 | 제출 폼 | 준회원(본인 것만)/정회원(전체) 뷰 차이, 미제출 상태 |

### (C) 완전 커스텀 화면 — 표준 패턴에서 벗어나는 것들
- **캘린더**: 월/주 단위 뷰, 이벤트 등록 폼(admin), 날짜별 이벤트 상세
- **과제게시판 제출현황 대시보드**: 과제 × 준회원 매트릭스 형태 (기술부용)
- **작품전시회 갤러리**: 카드형 그리드(사진+작품명+간단설명), 상세 팝업/페이지, 관리자 검토·승인 화면
- **기자재 대여 시스템**: 이미 구현된 별도 앱 — 신규 디자인 필요 여부는 별도 논의

## 4. 작품전시회 게시판 — 고정 작성 양식 (디자인에 직접 반영되는 부분)

정회원이 작성 시 아래 4개 필드가 고정 양식으로 제공됩니다. 그리드 카드형 갤러리로 노출:

- 작품명 (텍스트)
- 작품 사진 (이미지 업로드)
- 간단설명 (글자수 제한 — 구체 수치 미정)
- 제안서 (파일첨부)

승인 전 화면(정회원/기술부용 검토 화면)과 승인 후 공개 화면(전체공개 갤러리) 두 가지 상태를 함께 고려해야 합니다.

## 5. 자료실 — 참고용 기존 화면 구조

현재 NAS Drive(Synology Drive)에서 정회원이 자유롭게 폴더를 만들어 쓰는 방식을 그대로 이어받습니다(고정 카테고리 없음). 폴더 트리 탐색 + 업로드/다운로드 UI가 필요합니다.

## 6. 퍼블리싱 범위 — 확정

디자이너가 **HTML/CSS 퍼블리싱까지 담당**하기로 확정. 정적 HTML/CSS를 넘겨주시면 개발 쪽에서 Rhymix가 요구하는 템플릿 문법만 얹는 방식이라, (B) 표준 게시판 화면들과 (C) 커스텀 화면 전반의 마크업 작업 부담이 크게 줄어듦.

(C) 완전 커스텀 화면(캘린더 월/주 전환, 과제 대시보드 필터, 자료실 파일 트리 탐색 등)의 **JS 상호작용은 개발 쪽이 이어받기로 확정.** 디자이너는 정적 마크업/스타일까지만 제공.

## 7. 디자인 레퍼런스 — [한화비전](https://www.hanwhavision.com/ko)

디자인/구성 참조 대상으로 확정된 사이트. 실제 페이지를 열어 구조와 스타일 값을 직접 뽑아봤습니다.

### 톤 & 무드
- 하이테크·보안/영상장비 브랜드 특유의 **다크 네이비 + 오렌지 포인트** 톤. 배경은 흰색/연한 회색과 짙은 네이비-블랙을 섹션 단위로 교차 사용.
- 히어로/피처 섹션에 회로기판·열화상 카메라 영상 같은 **기술적 이미지**를 풀블리드로 깔고, 그 위에 반투명 카드나 뷰파인더 느낌의 브라켓 그래픽을 얹는 연출이 반복됨 — 전자/임베디드 계열 동아리인 KITEL과 톤이 잘 맞는 이유로 보임.

### 실측 디자인 토큰
| 항목 | 값 |
|---|---|
| 포인트 컬러(오렌지) | `#F37321` |
| 다크 섹션 배경 | `#050A2B` |
| 라이트 섹션 배경 | `#F7F7F7` |
| 기본 배경 | `#FFFFFF` |

| 버튼 모서리 | 약 3.5px — 거의 각진, 과하게 둥글지 않음 |
| 헤더 | 히어로 위에 반투명(rgba(0,0,0,0.2)) 플로팅 형태로 얹힘 |

### 구성(섹션) 패턴
1. **히어로**: 풀블리드 이미지/영상 배경 + 굵은 헤드라인 + 짧은 서브텍스트 + CTA 버튼, 자동 전환 캐러셀(슬라이드 번호 표시)
2. **기술/특징 하이라이트**: 다크 배경 + 배경 이미지 위에 반투명 카드 3개를 세로로 쌓아 각각 영문 타이틀 + 화살표 + 한글 서브텍스트로 소개
3. **카테고리 소개**: 2단 구성으로 주요 제품/기능 카테고리를 짧게 소개
4. **제품/콘텐츠 그리드**: 흰 배경에 카드형(이미지 중심 + 이름 + "더 보기") 그리드·캐러셀
5. **사례/분야 카드 그리드**: 아이콘 + 제목 + 1줄 설명으로 된 카드를 다수(18개) 그리드 배치 — KITEL로 치면 "활동 분야"나 "프로젝트 갤러리" 같은 곳에 응용 가능한 패턴
6. **뉴스 리스트**: 탭 필터(보도자료/특집기사/…) + 날짜·카테고리가 붙은 리스트 — Kitel News 목록 UI에 참고할 만함
7. **하단 CTA 2단**: 오렌지 그라데이션 배경의 문의 유도 블록 + 뉴스레터 구독 pill 버튼
8. **메가 푸터**: 7개 카테고리 컬럼으로 사이트 전체 사이트맵을 나열하며, **상단 GNB 카테고리명과 1:1로 정확히 대응**되는 구조(솔루션/제품/학습/파트너/지원/회사정보/뉴스및이벤트) — 일관성 있는 IA 설계의 좋은 예시

### KITEL 적용 시 참고 포인트
- 다크+오렌지(혹은 동아리 상징색) 톤과 기술적 배경 이미지 연출은 전자공학 동아리 정체성과 잘 어울릴 것으로 보임 — 디자이너가 컬러만 KITEL 브랜드에 맞게 조정하면 톤앤매너 자체는 그대로 참고 가능.
- "산업 분야 카드 그리드" 패턴은 §4의 작품전시회 갤러리나 About의 "연구분야" 섹션에 응용해볼 만함.
- GNB-푸터 사이트맵 1:1 대응 원칙은 §1의 메뉴 구조(About/Kitel News/Study/기타)에도 그대로 적용 가능.
