# 신규 사이트 IA / 권한 설계 (초안 v2)

작성일: 2026-08-19
목적: Rhymix 신규 사이트의 메뉴 구조와 게시판별 읽기/쓰기 권한을 확정하기 위한 작업 문서. 기존 사이트 분석은 [xeadmin-site-analysis.md](xeadmin-site-analysis.md) 참고.

## 1. 권한 모델

### 1-1. 기본 회원 등급

기존 사이트의 6단계 등급을 그대로 계승하되, 신규 사이트 기준으로 역할을 재정의함.

| 등급 | 정의 |
|---|---|
| admin | 임원진 산하 **정보부**의 사이트 관리 담당자가 매년 인수인계받는 단일 계정. 모든 게시판 읽기·쓰기 + 로그 조회 등 관리자 전용 기능 + **다른 회원/게시판의 읽기·쓰기 권한을 직접 변경 가능**(단 비밀번호 등 개인정보는 열람/변경 불가) |
| 임원진 | 동아리 운영진 |
| 정회원 | 동아리 정회원 |
| 준회원 | 동아리 준회원(1년간 선발 과정 진행 중) |
| 특별회원(졸업생) | **정회원과 동일한 권한으로 취급** |
| 가입대기 | 신규 가입 승인 대기 |

- "전체공개"는 **비로그인 방문자 포함**.
- 초안의 게시판별 권한 표기(정회원/준회원/전체공개 등)는 **admin을 제외한 일반 사용자 기준**으로 서술된 것임 (admin은 모든 게시판에 대해 항상 전체 읽기/쓰기 권한을 가짐).

### 1-2. 부서/역할 태그

임원진 산하 부서는 **정보부, 기술부, 섭외부, 총무부, 미화부** 5개. 이 중 사이트 상에서 특별 권한이 필요한 곳은 두 곳뿐이고 나머지 세 부서(섭외부/총무부/미화부)는 일반 임원진과 동일한 권한만 가짐(사이트 관리 기능 없음):

| 부서 | 사이트 내 특별 권한 |
|---|---|
| 정보부 | admin 계정을 매년 인수인계받아 사이트 전체 관리 담당 |
| 기술부 | 과제게시판 출제·채점 및 양식 편집, 작품전시회 조사·작품 파악·양식 결정 등 특별 작성 권한 |
| 섭외부 / 총무부 / 미화부 | 없음 (일반 임원진과 동일) |

→ 6단계 등급과 별개로 "임원진 + 부서 태그(정보부/기술부)"가 **동시에** 적용되는 구조가 필요함. Rhymix는 회원이 여러 그룹에 동시 소속될 수 있으므로(예: 임원진 + 기술부), 이 방식으로 구현 가능.

### 2-1. 캘린더

기존에는 "일정" 게시판에 admin이 캘린더 스크린샷 이미지를 올리는 방식이었음(완성도·관리 한계). 신규 사이트는 **실제 캘린더 UI(월/주 단위, 이벤트 등록)** 필요. admin만 등록/수정, 그 외 전원 조회만 가능. 임원진의 행사 일정은 내부 회의로 먼저 확정한 뒤 담당자가 캘린더에 등록하는 흐름.

### 2-2. Kitel News 본문 잠금 UX

다음/네이버 카페처럼 "로그인/가입 후 확인 가능" 형태의 잠금 표시. 게시판 내 모든 글에 일괄 적용(글쓴이가 글마다 공개범위를 선택하는 방식 아님).

### 2-3. 과제게시판

- 준회원은 **본인 제출물만** 조회 가능(다른 준회원 제출물 열람 불가).
- **기술부**가 과제 출제·채점을 담당하는 임원진 산하 부서 — 과제별 제출현황 대시보드 및 과제 양식(제출 규격) 편집 전용 UI가 기술부에게 필요.
- 세미나 과제, 품평회 과제 등 **1년간의 준회원 선발 과정**에서 제출이 필요한 과제를 다루는 게시판.

### 2-4. 자료실 — 참고: 기존 NAS Drive(Synology Drive) 폴더 구조

이관 시 유사한 카테고리 구조를 유지하는 방향으로 검토 중:

```
Team Folder
├── document
├── KITEL 관련 자료
│   ├── 2007년도
│   ├── 2008 작품전시회
│   ├── 2009 작품전시회
│   ├── 2010 책자
│   ├── 2011년
│   └── 축제자료실
├── 교육 자료
│   ├── 8051
│   ├── uCOS 실습동영상
│   ├── 교육영상(비트맵)
│   ├── 데이터시트
│   ├── 영어 학습 자료
│   ├── 작품&세미나&학술제관련자료
│   ├── 파이썬 인강
│   └── 프로그래밍 학습 동영상
├── 대회 공모전
│   ├── 2006 시립대 라인트레이서
│   ├── 2009 임베디드 소프트웨어
│   ├── 2009 한양대 대회
│   ├── 2011 임베디드 공모전
│   └── 2012 서울메트로
└── 임원단
    └── (2019년 ~ 2026년, 연도별)
```

현재 NAS Drive 계정 체계는 홈페이지 회원 체계와 별도로 관리되고 있으며, 자료실은 정회원이 가장 많이 사용하는 기능이라 홈페이지로 이관 시 활성화 효과가 기대됨. 신규 자료실의 UI/조작 방식은 NAS Drive와 크게 다르지 않게 구성하는 방향.

**카테고리(폴더) 구조는 고정하지 않음.** 현재 NAS Drive에서도 정회원이 자유롭게 폴더를 생성할 수 있는 방식이므로, 신규 자료실도 admin이 관리하는 고정 폴더 구조가 아니라 **정회원이 자유롭게 폴더를 만들 수 있는 방식을 그대로 유지**함. 위 구조는 어디까지나 현재 실제 사용 예시로 참고.

## 4. 확정 사항 요약 (2차 확인 반영)

1. 부서는 정보부·기술부·섭외부·총무부·미화부 5개, 사이트 특별 권한은 정보부(admin 인수인계)와 기술부(과제·작품전시회 관련)뿐. (1-2 반영)
2. 작품전시회 게시 승인 주체는 **admin**. (2번 표 반영)
3. 과제게시판은 정회원도 전체 열람 가능. 피드백은 사이트 기능으로 만들지 않음(오프라인/개인 연락). (2-3 반영)
4. 자료실 카테고리는 고정하지 않고 NAS Drive처럼 정회원이 자유롭게 폴더 생성. (2-4 반영)

## 5. 남은 미정 사항

- **"기타" 메뉴 정식 이름**: 우선 "기타"로 유지, 추후 별도 회의를 통해 확정 예정. 이름이 확정되면 이 문서와 실제 메뉴 라벨을 함께 갱신 필요.
